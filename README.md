# HR Estudio Fotografía — Agenda de sesiones

Agenda web independiente para solicitudes de sesiones fotográficas de 30 minutos, calendario administrativo, horarios extraordinarios y tickets imprimibles.

**Horarios:** lunes a viernes 18:00–20:00; sábado 15:00–20:00; domingo 10:00–18:00 (Tabasco, México).

**Instalación:** descomprime el archivo `hr-estudio-agenda.zip` (carpeta `hr-agenda/`) o utiliza el código fuente del proyecto. Crea una base de datos Supabase independiente, ejecuta `supabase/schema.sql`, configura las variables indicadas en `.env.example` en Vercel y ejecuta `npm install` + `npm run build`.

**Estado:** prototipo inicial, no habilitado todavía para clientes. Aún falta configurar Supabase, variables de entorno y desplegarlo. Google Calendar no se sincroniza automáticamente todavía.

**Seguridad:** no subir contraseñas ni claves privadas a GitHub. Configurar HTTPS, contraseñas robustas y protección antispam antes del uso público.
